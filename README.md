# 🇩🇪 German Citizenship Test (Einbürgerungstest)

All **300 general + 160 state-specific** questions from the official **BAMF Einbürgerungstest / Leben in Deutschland** test catalog — free, with correct answers highlighted ✅ and explanations, in **6 languages**.

Based on the official BAMF catalog (Stand: 07.05.2025).

> ⚠️ **Important:** For educational purposes only. Questions about current officeholders (Chancellor, Minister-Presidents) change with elections — always verify on the [BAMF website](https://www.bamf.de) before your test.

## 📂 About This Branch

This is the **`html`** branch — the built, deployed output of the site (what actually runs at [leben.wordfeather.com](https://leben.wordfeather.com/)). It's generated automatically by `build.js` and contains the compiled `en/`, `ur/`, `ar/`, `de/`, `tr/`, `ru/` pages, `quiz.html`, `quiz-data.json`, and related assets.

**If you want to read or browse the question content directly** (as plain-text markdown, with correct answers and explanations), check the source branches instead:

| Branch | Content |
|---|---|
| [`english`](https://github.com/abdullahbutt/leben-in-deutschland-test/tree/english) | Questions + explanations in English |
| [`urdu`](https://github.com/abdullahbutt/leben-in-deutschland-test/tree/urdu) | Questions + explanations in Urdu |
| [`arabic`](https://github.com/abdullahbutt/leben-in-deutschland-test/tree/arabic) | Questions + explanations in Arabic |

German, Turkish, and Russian content is generated separately (via `de-explanations.json`, `tr-questions.json` / `tr-explanations.json`, `ru-questions.json` / `ru-explanations.json` on this branch) rather than kept as its own markdown source branch.

## 🛠️ For Developers

This branch is regenerated by running:

```bash
npm run build
```

which reads the markdown source from the `english`/`urdu`/`arabic` branches (mounted as git worktrees under `sources/`) plus the `*-questions.json` / `*-explanations.json` dictionaries, and writes out the full static site — HTML pages for all 6 languages, `quiz-data.json`, `sitemap.xml`, and a stamped `sw.js` service worker.

`check-quiz-data.js` runs a structural/content sanity check afterward (question counts, missing translations, broken image references, etc.) — worth running after any content change:

```bash
node check-quiz-data.js
```

See [CONTRIBUTING.md](CONTRIBUTING.md) for more on the project structure.
